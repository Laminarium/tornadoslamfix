# Tornado Slam Fix

Mod that fixes inverse attack speed scaling of Drifter's alternate utility - Tornado Slam.

### Vanilla behaviour
 More attack speed means:
 - less frequent same enemy hits;
 - less frequent bounces;
 - slower spinning animation.
